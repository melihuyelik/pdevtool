PDevTool

PDevTool is a desktop developer tool that opens SSH tunnels, dumps PostgreSQL databases through their bastion hosts, and keeps project notes and a request library.

Encrypted Google Drive backup

Users can optionally connect their own Google account to back up their PDevTool settings, notes and keys. The backup is encrypted on the user's device with a backup password that only the user knows, and is stored in the hidden application data folder of the user's own Google Drive. The developer never receives or stores this data.
